# Mayella's Software Workshop

**Building practical software, exploring AI, and solving real-world problems.**

Mayella's Software Workshop is an independent software initiative focused on making useful technology more accessible to educators, organizations, and small businesses.

## About

Building on my experience at San Diego State University (SDSU) and a technology startup, I'm exploring how software and AI can help people work more effectively, solve everyday challenges, and bring new ideas to life.

My approach starts with understanding a problem, exploring possible solutions, and building something useful.

I'm especially interested in bringing the problem-solving and technology experience I've gained through education and startup work to local businesses and organizations.

## What I'm Building

- **Web applications:** Interactive, accessible tools designed around real needs.
- **AI-powered solutions:** Exploring how artificial intelligence can support learning, creativity, and everyday workflows.
- **Education technology:** Tools that make teaching, learning, and knowledge sharing more effective.
- **Small-business tools:** Exploring ways to help businesses streamline operations and solve practical problems.

## Technology

Next.js · React · TypeScript · AI-assisted development · Vercel

I'm continuously learning and expanding the technologies I work with.

## Philosophy

Good technology should make people's lives easier, expand what they're capable of, and solve problems that matter.

I believe useful software starts with curiosity, empathy, experimentation, and a willingness to learn.

## Development

This website is built with Next.js and TypeScript and deployed through Vercel.

To run locally:

```bash
npm install
npm run dev
```

Then visit `http://localhost:3000`.
